# Models

Trained models and checkpoints live here.

- Serialise final models as `joblib`/`pkl` files (scikit-learn) or checkpoint
  folders (deep learning).
- Record each model's **version, metrics, and dataset** in the thesis
  experiments table (see `docs/thesis_outline.md`).
- Large files should not be committed directly — use Git LFS or an external
  registry (e.g. Hugging Face Hub, Weights & Biases).
